Что это?

army_system_py — это персональная CLI-система для отслеживания, анализа и стабилизации психоэмоционального состояния в условиях военной службы. Создана солдатом для самого себя в Termux на Android, чтобы выжить в армии.

Возможности

· Замеры состояния: запись оценки по шкале 0–10 с временной меткой и комментарием.
· Экстренные протоколы: PANIC (grounding + дыхание 4-4-6) и RECOVERY (дыхание 4-6).
· GATE: шлюз безопасности для предотвращения импульсивных сообщений (блокировка при состоянии ≤ 3 или активной дельте).
· Аналитика: анализатор паттернов, детектор аномалий, коррелятор связей, предиктор.
· Дашборд: интерактивный TUI (Textual).
· Расширенные модули: дневник, таймлайн, сравнение периодов, немецкий язык, импорт данных, напоминания, погода, цитаты.
· Плагины на Lua: автоматическое включение дельты и рекомендации при гамма-состояниях.

Технологии

· Python 3.11+
· Textual (TUI-фреймворк)
· SQLite3 (база данных)
· Lua 5.4 (плагины)
· Bash-скрипты (старая система)
· Termux (среда запуска)

Установка и запуск

```bash
git clone <репозиторий>
cd army_system_py
pip install textual
python menu.py
```

Команды CLI

Команда Описание
state Записать состояние
last Последний замер
summary Сводка на сегодня
panic Антипанический протокол
recovery Протокол восстановления
gate Шлюз безопасности
analyze Анализатор паттернов
predict Прогноз на завтра
