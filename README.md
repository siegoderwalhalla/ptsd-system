# PTSD Monitor 🧠

Система персонального мониторинга психического здоровья для работы с ПТСР (посттравматическое стрессовое расстройство).

## 🎯 Возможности

- **Трекинг состояния**: Ежедневная запись эмоционального состояния, уровня тревоги, качества сна и энергии
- **Учет триггеров**: Фиксация ситуаций, вызывающих стрессовые реакции (конфликты, одиночество, навязчивые воспоминания и др.)
- **Панические атаки**: Быстрая запись эпизодов паники с детализацией симптомов и длительности
- **Техники восстановления**: Каталог упражнений для саморегуляции с отслеживанием эффективности
- **Защитные механизмы**: Мониторинг использования стратегий совладания (копингов)
- **Аналитика**: Выявление паттернов, корреляций и аномалий в динамике состояния
- **Предсказания**: Прогнозирование рисков ухудшения состояния на основе исторических данных
- **Экспорт/Импорт**: Выгрузка данных в JSON/Markdown и восстановление из резервных копий
- **TUI-интерфейс**: Удобный терминальный интерфейс для визуализации данных

## 🚀 Быстрый старт

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Первое использование

1. **Инициализация базы данных** (происходит автоматически при первом запуске)
2. **Запись состояния**:
   ```bash
   python cli.py state --score 7 --anxiety 5 --sleep 6 --energy 4
   ```
3. **Запуск TUI-интерфейса**:
   ```bash
   python tui.py
   ```

## 📖 Использование CLI

### Основные команды

#### Запись состояния
```bash
python cli.py state --score 8 --anxiety 3 --sleep 7 --energy 6 --notes "Чувствую себя лучше"
```

#### Регистрация триггера
```bash
python cli.py trigger --code TRIGGER_CONFLICT --intensity 7 --notes "Ссора с коллегой"
```

#### Паническая атака
```bash
python cli.py panic --severity 8 --duration 20 --symptoms "heart_racing,dizziness"
```

#### Техника восстановления
```bash
python cli.py recovery --technique "breathing" --effectiveness 7 --notes "Помогло успокоиться"
```

#### Защитный механизм
```bash
python cli.py gate --mechanism "avoidance" --effectiveness 5
```

#### Статистика
```bash
python cli.py stats --days 30
```

#### Анализ паттернов
```bash
python cli.py analyze
```

#### Предсказание состояния
```bash
python cli.py predict
```

#### Экспорт данных
```bash
# В JSON
python cli.py export --format json --output my_data.json

# В Markdown
python cli.py export --format markdown --output report.md
```

#### Импорт данных
```bash
python cli.py import --file backup.json
```

#### Резервное копирование
```bash
python cli.py backup --create
```

#### Запуск TUI
```bash
python cli.py tui
# или
python tui.py
```

### Справочник кодов триггеров

| Код | Описание |
|-----|----------|
| `TRIGGER_ABUSE` | Абьюзивное взаимодействие |
| `TRIGGER_CONFLICT` | Конфликтная ситуация |
| `TRIGGER_LONELY` | Чувство одиночества |
| `TRIGGER_INTRUSIVE` | Навязчивые воспоминания |
| `TRIGGER_DEATH` | Тема смерти, утраты |
| `TRIGGER_GUILT` | Чувство вины, стыда |
| `TRIGGER_IMPULSE` | Импульсивные желания |
| `TRIGGER_GENERAL` | Общий триггер |
| `THOUGHT` | Негативные мысли о себе |
| `SLEEP` | Проблемы со сном |
| `DREAM` | Триггерные сны |

### Шкалы оценки

- **Score (1-10)**: Общее самочувствие (1 — очень плохо, 10 — отлично)
- **Anxiety (0-10)**: Уровень тревоги (0 — спокоен, 10 — паника)
- **Sleep (0-10)**: Качество сна (0 — не спал, 10 — выспался)
- **Energy (0-10)**: Уровень энергии (0 — истощение, 10 — полон сил)
- **Intensity (0-10)**: Сила воздействия триггера
- **Severity (0-10)**: Тяжесть панической атаки
- **Effectiveness (0-10)**: Эффективность техники/механизма

## 🖥️ TUI-интерфейс

Запустите `python tui.py` для доступа к интерактивному интерфейсу с экранами:

- **Dashboard**: Обзор текущего состояния и статистики
- **State**: Форма записи состояния
- **Panic**: Журнал панических атак
- **Recovery**: Каталог техник восстановления
- **Gate**: Мониторинг защитных механизмов
- **Analyze**: Визуализация паттернов и корреляций
- **Predict**: Прогнозы на основе данных
- **Report**: Генерация отчетов
- **Journal**: Дневник записей

Навигация: используйте `Tab` для переключения между полями, `Enter` для подтверждения, `q` или `Ctrl+C` для выхода.

## 🔒 Конфиденциальность

Все данные хранятся локально в файле `data/ptsd.db`. Никакая информация не отправляется на внешние серверы. Регулярно создавайте резервные копии с помощью команды `python cli.py backup --create`.

## ⚠️ Важное замечание

PTSD Monitor — это инструмент для самопомощи и отслеживания динамики состояния. Он **не заменяет** профессиональную психотерапевтическую помощь. При серьезных симптомах обратитесь к квалифицированному специалисту.
